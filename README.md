# Employee Management UI

A simple Employee Management page built with React and Vite for the Meepl HRMS task (MEEPLP1-3649).

## Features
- View employees in a table
- Search employees by name
- Add, edit and delete employees
- Form validation and success messages
- Data is stored in React state (no backend)

## Tech Stack
React.js, Vite, JavaScript, CSS

## Run Locally
npm install
npm run dev
